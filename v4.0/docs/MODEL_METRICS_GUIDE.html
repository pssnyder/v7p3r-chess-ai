Classification Metrics

Accuracy
Accuracy = Correct / Total
What it measures: Overall correctness of predictions
Range: 0 to 1 (0% to 100%)
Your case: 88 correct moves out of 100 = 0.88
Chess Example:
88% of V7P3R's moves match Stockfish's top 5 recommendations
Precision
Precision = TP / (TP + FP)
What it measures: When you predict "good move", how often are you right?
Range: 0 to 1
High precision: Few false alarms
Chess Example:
Of all moves your AI recommends, what % are actually strong?
Recall (Sensitivity)
Recall = TP / (TP + FN)
What it measures: Of all good moves, how many did you find?
Range: 0 to 1
High recall: Catches most opportunities
Chess Example:
Of all winning moves available, what % does your AI identify?
⭐ F1 Score
F1 = 2 × (Precision × Recall) / (Precision + Recall)
What it measures: Balance between precision and recall
Range: 0 to 1
Target: > 0.85 for chess AI

Regression Metrics

MAE (Mean Absolute Error)
MAE = Σ|predicted - actual| / n
What it measures: Average distance from truth
Units: Same as your data (centipawns)
Target: < 20 centipawns for heuristics
Chess Example:
If MAE = 15, your heuristic predictions are off by 15 centipawns on average
RMSE (Root Mean Squared Error)
RMSE = √(Σ(predicted - actual)² / n)
What it measures: Like MAE but penalizes big errors more
Units: Same as your data
Target: < 30 centipawns
Interpretation:
RMSE > MAE means you have some large outlier errors
⭐ R² Score
R² = 1 - (SS_res / SS_tot)
What it measures: % of variance explained by model
Range: -∞ to 1 (usually 0 to 1)
Interpretation:
  • 1.0 = Perfect predictions
  • 0.7 = Explains 70% of variance
  • 0.0 = No better than mean
  • <0 = Worse than mean

Correlation Metrics

Pearson Correlation (r)
r = Cov(X,Y) / (σ_X × σ_Y)
What it measures: Linear relationship strength
Range: -1 to +1
Interpretation:
  • +1 = Perfect positive correlation
  • 0 = No linear correlation
  • -1 = Perfect negative correlation
Spearman Correlation (ρ)
ρ = Pearson(rank(X), rank(Y))
What it measures: Monotonic relationships (order matters)
Range: -1 to +1
Better for: Move ranking, non-linear patterns
Chess Example:
Measures how well your AI's move rankings match Stockfish's order

Statistical Significance

P-Value
What it measures: Probability results occurred by chance
Convention: p < 0.05 = "statistically significant"
Interpretation:
  • p = 0.01: 1% chance it's random luck
  • p = 0.05: 5% chance (threshold)
  • p = 0.10: 10% chance (borderline)
⚠️ Warning:
Statistical significance ≠ Practical significance!
Confidence Intervals
95% CI = μ ± 1.96 × (σ / √n)
What it measures: Range where true value likely falls
Example: Accuracy = 88% ± 6% (95% CI: 82-94%)
Rule: Larger sample → narrower interval

Overfitting vs Underfitting

Underfitting

📉

Symptoms:

  • Low train accuracy
  • Low test accuracy
  • High bias

Fix: More complex model, better features

Good Fit ✓

🎯

Symptoms:

  • High train accuracy
  • High test accuracy
  • Small gap

Goal: This is what you want!

Overfitting

📊

Symptoms:

  • High train accuracy
  • Low test accuracy
  • High variance

Fix: More data, regularization, simpler model

🎯 Best Practices for Your Chess AI

  • Primary metric: Use Top-5 Accuracy (currently 88%) as your main KPI
  • Regression tracking: Monitor MAE for each heuristic (material, PST, pawn structure, etc.)
  • Validation: Use 5-fold cross-validation with your 100 positions
  • Confidence weighting: Weight Rank #1 moves (1.0) higher than Rank #2+ (0.8)
  • Data scaling: Test with 100 → 1000 positions and watch learning curves
  • Overfitting watch: With only 100 positions, high risk - use regularization
  • Report format: Always include confidence intervals (e.g., "88% ± 6%")
  • Statistical significance: Run multiple training runs, report mean ± std
  • Correlation check: Track Spearman correlation for move ranking quality
  • Learning curves: Plot performance vs dataset size to find sweet spot
