# V7P3R AI v5.2 - Wide Architecture Implementation

## Executive Summary

**Goal:** Break through the 45% policy accuracy plateau identified in v5.1+TPF training.

**Solution:** Widen neural network architecture from 256→256→128→64 to 512→512→256→128.

**Status:** 🟡 Ready to train

---

## Architecture Comparison

### v5.1 (Current - Plateaued)
```
Input: 325 features
Shared: 256 → 256 → 128 → 64
Policy: 64 → 6 classes
Value: 32 → 1 value
Parameters: 323,079
```

**Performance:**
- Policy Accuracy: 45.15%
- Top-2 Accuracy: 65.38%
- Value MAE: 0.0745
- Status: Plateaued at epoch 36, no improvement for 15 epochs

**Plateau Analysis:**
- ✅ NOT overfitting (train-val gap healthy: 0.087)
- ✅ LR reductions tried (3 cycles: 0.001 → 0.000125)
- ❌ Architecture capacity maxed out
- ❌ Validation accuracy stuck at 45% for 25 epochs

### v5.2 (Proposed - Wide)
```
Input: 325 features
Shared: 512 → 512 → 256 → 128
Policy: 128 → 6 classes  
Value: 64 → 1 value
Parameters: 953,351 (+2.95x)
```

**Expected Performance:**
- Policy Accuracy: 50-53% (target: +5-8pp)
- Top-2 Accuracy: 72-76% (target: >75%)
- Value MAE: 0.065-0.070 (target: maintain/improve)
- Training time: ~25min per 50 epochs (2x slower)

---

## Rationale

### Why Architecture Widening?

**Evidence from v5.1 training:**

1. **Train loss still decreasing** (epoch 51: 1.364) → Model can learn more
2. **Val loss plateaued** (epoch 36-51: 1.439 ↔ 1.451) → Can't generalize better
3. **Healthy train-val gap** (0.087) → NOT overfitting
4. **Val accuracy stuck** (45% for 25 epochs) → Architecture capacity limit

**Interpretation:** Model has learned all patterns it CAN represent, not all patterns that EXIST in data.

### Why 3x Parameters?

**Feature-to-Parameter Ratio:**
- v5.1: 325 features / 323k params = ~1000 params/feature
- v5.2: 325 features / 953k params = ~2900 params/feature

**Similar Architectures:**
- AlphaZero: 256 features → 80M params (~312k params/feature)
- Leela Chess: 112 planes → 350M params (~3M params/feature)
- Our v5.2: Still conservative, room to grow

### Why Not Deeper?

- **Current depth:** 4 shared layers (adequate for chess)
- **Residual connections:** Already enable gradient flow
- **Wider > Deeper:** For tabular features, width captures more feature interactions
- **Temporal features:** Need width to combine historical + current patterns

## Risk Assessment

### Low Risk ✅
- **Overfitting:** Early stopping + dropout (0.3) + L2 regularization
- **Memory:** 3.6MB model (CPU-friendly)
- **Data quality:** Same preprocessed data as v5.1 (validated)

### Medium Risk ⚠️
- **Training time:** 2x longer (~40min vs 20min) - acceptable
- **Convergence:** Might need more epochs (100 → 120) - acceptable
- **LR tuning:** May need lower initial LR (0.001 → 0.0005) - easy to adjust

### Mitigations
- Monitor train-val gap closely (stop if >0.15)
- Use same class weights as v5.1 (force rare grade learning)
- Keep early stopping patience high (20 epochs)
