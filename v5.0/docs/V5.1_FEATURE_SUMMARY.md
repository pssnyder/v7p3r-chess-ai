## 🎯 Key New Feature Groups

### 1. **Tactical Detection (F040-F049)** - CRITICAL
Expanded from 4 → 20 features to distinguish subtle tactical differences:
- En prise value (total material hanging)
- Fork threats (knight/queen attacking 2+ pieces)
- Pins (pieces pinned to king/valuable piece)
- Skewers (valuable piece attacked with less valuable behind)
- Discovered attacks (moving piece exposes attack)
- Trapped pieces (mobility < 3)
- Back rank threats (mate threats on back rank)

**Impact**: Helps AI distinguish 2nd/3rd/4th best moves based on tactical nuances

### 2. **Multi-Move Context (F100-F114)** - CRITICAL
Gives AI the **full spectrum** of move quality (fixes binary classification):
- Top-5 move evaluations from Stockfish
- Eval gaps between alternatives
- Position sharpness (tactical vs positional)
- Move diversity (how many good options exist)
- Move type categorization (capture/check/quiet/promotion)
- Alternative move quality (moves within 50cp of best)

**Impact**: AI learns **grades 1-4** by understanding the spectrum, not just "best" vs "worst"

### 3. **Rook Placement (F060-F064)**
- Rooks on open/semi-open files
- Rooks on 7th rank
- Connected rooks
- Rook activity score (normalized mobility)

**Impact**: Better endgame understanding, strategic piece placement

### 4. **Enhanced Pawn Structure (F024-F029)**
- Backward pawns (behind neighbors)
- Pawn chains (longest connected pawns)
- Advanced pawns (past 4th rank)
- Pawn islands (disconnected groups)

**Impact**: Better positional understanding, recognizes weak pawn structures

### 5. **Knight Outposts (F070-F071)**
- Knights on strong squares (protected, in enemy territory)
- Average knight mobility

**Impact**: Recognizes strong knight placements

### 6. **Center Control & Development (F080-F091)**
- Center pawn count
- Center control score (attacks on d4/d5/e4/e5)
- Space advantage (squares controlled in enemy half)
- Pieces developed (off back rank)

**Impact**: Better opening/middlegame understanding

## 🎓 Why This Should Work

### Problem 1: Binary Classification
**Root Cause**: Only 26 features → can't distinguish 2nd vs 3rd vs 4th best moves  
**Solution**: 101 features with tactical nuance (forks, pins, skewers, trapped pieces)

### Problem 2: No Move Spectrum Knowledge
**Root Cause**: AI only knows "V7P3R's move" and "best move", not the alternatives  
**Solution**: F100-F114 gives full top-5 context, eval gaps, position sharpness

### Problem 3: Class Imbalance
**Root Cause**: Grade 5 (40.6%) and Grade 0 (24.6%) dominate dataset  
**Solution**: Class weights (1.0, 5.0, 3.5, 2.5, 1.8, 1.0) force model to learn rare grades

### Synergy Effect
More features + class weighting + multi-move context = Model learns **entire spectrum** of move quality, not just extremes.
