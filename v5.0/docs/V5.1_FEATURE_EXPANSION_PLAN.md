# V7P3R AI v5.1 - Feature Expansion Plan
**Comprehensive Strategy to Improve Move Quality Classification**

---

## 🎯 Problem Analysis

### Current State (v5.0)
- **26 features** (5 core, 6 king safety, 8 pawn, 6 piece activity, 4 tactical, 4 move context)
- **Binary classification**: Model only predicts grades 0 or 5
- **Test accuracy: 49.12%** (but only distinguishes "best" vs "worst")
- **130+ heuristics available** from V7P3R v18.3 but not utilized

### Root Causes
1. **Insufficient feature diversity** - Can't distinguish 2nd vs 3rd vs 4th best moves
2. **Class imbalance** - Model biased toward grades 0 and 5 (most common in dataset)
3. **Missing tactical nuance** - No fork/pin/skewer detection, no SEE, no hanging piece details
4. **No opening knowledge** - Trained only on V7P3R's games (which start from varied positions)
5. **Single-move features** - No context about alternative moves (top-5 Stockfish grading)
6. **No transposition awareness** - Can't link related patterns or work toward target positions

### Phase 2: Multi-Move Context Features (Target: +15 features → 101 total)

#### **Top-5 Stockfish Move Analysis (F100-F114)** - 15 features
Currently: Only knows if V7P3R's move matched best move
**ADD:**
- `F100_best_move_eval_cp` - Stockfish eval of best move
- `F101_second_move_eval_cp` - Eval of 2nd best move
- `F102_third_move_eval_cp` - Eval of 3rd best move
- `F103_fourth_move_eval_cp` - Eval of 4th best move
- `F104_fifth_move_eval_cp` - Eval of 5th best move
- `F105_eval_gap_best_to_second` - Difference between #1 and #2
- `F106_eval_gap_second_to_third` - Difference between #2 and #3
- `F107_v7p3r_move_eval_cp` - Eval after V7P3R's move
- `F108_v7p3r_eval_loss` - How much worse than best move
- `F109_move_diversity_score` - Spread of top-5 evaluations (variance)
- `F110_position_sharpness` - Large eval gaps = tactical position
- `F111_best_move_type` - Categorical: capture/check/quiet/promotion
- `F112_second_move_type` - Same categorization
- `F113_v7p3r_move_type` - Same categorization
- `F114_alternative_move_quality` - How many top-5 moves are within 50cp

**Purpose**: 
- Gives AI context about **what alternatives existed**
- Helps distinguish "forced best move" vs "many good options"
- Teaches AI when position is sharp (one good move) vs positional (many playable moves)
- **Critical for fixing binary classification** - AI learns the full spectrum

**Source**: Stockfish multipv=5 analysis (already in dataset from `grade_with_stockfish.py`)

### Phase 3: Opening Book Integration (Target: +10,000 positions)

#### **Opening Ingestor Script**
Create `scripts/extract_opening_positions.py`:

**Purpose**: Extract opening positions from PGN databases without flooding dataset

**Algorithm**:
1. Load opening PGN database (e.g., "Sicilian_Defense.pgn")
2. For each game:
   - Extract first **10-15 moves** only
   - Convert to FEN positions
   - Check if position already exists in dataset (avoid duplicates)
   - Check if transposition already exists (use Zobrist hash or FEN canonical form)
3. Limit to **100-200 unique positions per opening**
4. Grade with Stockfish (same multipv=5 protocol)
5. Add to master dataset

**Opening Databases to Process**:
- Sicilian Defense (~200 positions)
- Ruy Lopez (~150 positions)
- Queen's Gambit (~150 positions)
- King's Indian Defense (~150 positions)
- French Defense (~100 positions)
- Caro-Kann (~100 positions)
- English Opening (~100 positions)
- Nimzo-Indian (~100 positions)
- **Total: ~1,000 opening positions**

**Feature Enhancement**:
- `F115_opening_book_position` - Boolean: Is this from opening book
- `F116_opening_name` - Categorical: ECO code or opening name
- `F117_moves_from_start` - Count of moves from starting position

### Phase 4: Transposition & Pattern Features (Target: +20 features → 131 total)

#### **Pawn Structure Hash (F120-F125)** - 6 features
**Purpose**: Help AI recognize similar pawn structures across different piece configurations

**ADD**:
- `F120_pawn_structure_hash` - Zobrist hash of pawn positions only
- `F121_pawn_structure_type` - Categorical: open/closed/semi-open
- `F122_pawn_tension_squares` - Count of squares where pawns face each other
- `F123_pawn_breaks_available` - Count of possible pawn breaks
- `F124_pawn_structure_similarity` - Cosine similarity to known "good" structures
- `F125_pawn_structure_symmetry` - Measure of symmetry (0-1)

**How it helps transposition learning**:
- AI learns "IQP positions are similar even with different pieces"
- Recognizes "minority attack pattern" regardless of piece placement
- Links positions with similar pawn structure for strategy transfer

#### **Piece Coordination (F130-F134)** - 5 features
**Purpose**: Detect long-term strategic patterns

**ADD**:
- `F130_piece_harmony_score` - How well pieces support each other (0-1)
- `F131_battery_count` - Rooks/queen on same file/rank/diagonal
- `F132_piece_clustering` - Std dev of piece distances (spread vs clustered)
- `F133_attack_on_weak_squares` - Pieces targeting holes in opponent structure
- `F134_prophylaxis_score` - Pieces preventing opponent's ideas

**How it helps**:
- AI learns to coordinate pieces toward goals
- Recognizes minority attack, IQP pressure, king hunt patterns
- Understands **working toward a position** not just making best immediate move

#### **Move Sequence Encoding (F140-F144)** - 5 features
**Purpose**: Give AI short-term memory of recent moves

**ADD**:
- `F140_last_move_type` - Categorical: capture/check/quiet/etc
- `F141_last_move_piece` - What piece moved
- `F142_last_move_created_threat` - Boolean
- `F143_move_follows_plan` - Is this part of a sequence (heuristic)
- `F144_position_after_forced_line` - Boolean: position after forced exchange

**How it helps**:
- AI learns move sequences, not just isolated positions
- Understands tactical combinations (sacrifice → checkmate)
- Recognizes "quiet move setting up tactics 2 moves later"

#### **Position Evaluation History (F150-F154)** - 4 features
**Purpose**: Track eval trend to understand improving/declining positions

**ADD**:
- `F150_eval_trend` - Categorical: improving/declining/stable
- `F151_eval_volatility` - Std dev of last N moves' evals
- `F152_critical_position` - Boolean: eval swing >1.5 pawns in last 3 moves
- `F153_position_complexity` - Stockfish depth needed to stabilize eval

**How it helps**:
- AI learns when position is getting better/worse
- Recognizes critical moments vs routine play
- Understands when to push advantage vs consolidate
