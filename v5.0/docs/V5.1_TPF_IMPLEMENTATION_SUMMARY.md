## 🧠 The TPF Concept (Your Innovation!)

**Temporal Persistence Features** = Giving the AI "Memory"

### Core Principle
```
ΔFeature = Feature_current - Feature_historical
```

Instead of just seeing **"rook on open file"**, the AI now understands:
- **"Rook JUST MOVED to open file"** (new tactical opportunity)
- **"Rook WAS ALREADY on open file"** (sustained pressure pattern)

This is like **differential calculus for chess positions** - the AI learns momentum and sequences, not just snapshots.

### Implementation Strategy
```python
# Puzzle sequences (multi-move PVs available)
has_history = 1  # Populate all temporal features
historical_features = calculate_features(previous_fen)
move_encoding = encode_move(last_move_uci)  # from_square, to_square, piece_type

# Game positions (no multi-move context)
has_history = 0  # Set temporal features to null sentinels
historical_features = [-1, -999.0, ...]  # Model learns to ignore when no history
move_encoding = [-1, -1, 0]

# Self-play (future enhancement)
has_history = 1  # Engine maintains state between moves
# Perfect for reinforcement learning integration
```

## 🎓 Technical Deep Dive

### Architecture Remains Unchanged (By Design!)
```
Input Layer:  26 → 262 features (10x expansion handled gracefully)
  ↓
Shared Embedding:
  Linear(262 → 256) + ResidualBlock(256 → 256)
  ResidualBlock(256 → 128)
  ResidualBlock(128 → 64)
  ↓
Policy Head (move quality):
  Linear(64 → 64) + ReLU + Dropout
  Linear(64 → 6) [grades 0-5]
  CrossEntropyLoss with class weights [1.0, 5.0, 3.5, 2.5, 1.8, 1.0]
  
Value Head (position eval):
  Linear(64 → 32) + ReLU + Dropout
  Linear(32 → 1) [range: -1 to +1]
  HuberLoss (delta=0.5)

Parameters: 164,491 (v5.0) → ~232,000 (v5.1+TPF)
  - Increase mostly in input layer (262 vs 26)
  - Hidden layers identical (residual design handles feature growth)
```

### Why This Works
1. **Deep architecture** (256→256→128→64) provides capacity for feature learning
2. **Residual connections** enable gradient flow even with 262 inputs
3. **Batch normalization** stabilizes training with expanded feature space
4. **Dropout (0.3)** prevents overfitting despite 10x feature increase
5. **Class weights** force model to learn rare grades (no binary collapse)

### Null Sentinel Handling
```python
# StandardScaler handles -999.0 gracefully (outlier clipping)
# Model learns to ignore sentinel values via training patterns

# Example: Game position (no history)
white_en_prise_value_historical = -999.0  # Obvious null
has_history = 0                            # Context flag

# Puzzle sequence (with history)
white_en_prise_value_historical = 0.0      # Actual value
has_history = 1                            # Valid context
```

The model learns the correlation:
- `has_history=0` → ignore all historical features
- `has_history=1` → use temporal features for differential learning
