# V7.2 "Matrix Plug-in" Training System

## The Problem (v7.1)
- Generation 0 (random weights) too weak to play chess
- Self-play training couldn't differentiate Gen 0 vs Gen 1
- Result: 90% draws, 0% acceptance rate

## The Solution (v7.2)
**"Matrix Plug-in" Knowledge Injection**

Instead of random initialization → **Pre-train from grandmaster games**

### Why This Works:
1. **Fast**: 10k positions in 10 minutes (vs 100 games in 4-6 hours)
2. **Effective**: Learning from actual winning chess
3. **Simple**: Still single-model architecture
4. **Flexible**: Can inject knowledge anytime

## Three-Step Workflow

### Step 1: Clean PGN Files
```bash
cd v7.0/src
python pgn_preprocessor.py
```

**What it does:**
- Removes commentary `{like this}`
- Removes variations `(like this)`
- Removes annotations `!`, `?`, `$2`, etc.
- Creates clean PGN files in `/cleaned` subdirectories

**Expected output:**
```
Processing: tarrasch_300_games.pgn
Found 300 games
Cleaned 300/300 games...
✓ Wrote 298 clean games to: tarrasch_300_games_clean.pgn
```

**Directories processed:**
- `pgn_data_tactics/` → Combinations, positional play
- `pgn_data_important_games/` → 100 golden games, Tarrasch, Lasker
- `pgn_data_general/` → Art of Chess Analysis

---

### Step 2: Supervised Pre-Training
```bash
cd v7.0/src
python supervised_gm_trainer.py
```

**What it does:**
- Parses cleaned PGN files
- Identifies game winner
- Extracts features from **winner's positions only**
- Trains network with high target values (+0.6 to +0.93)
- Creates competent baseline in ~10 minutes

**Key insight:**
> "Every game has a winner and a loser. We only learn from the winner's moves,
> giving the network instant 'good chess' knowledge."

**Expected output:**
```
Loading from: pgn_data_important_games/cleaned
✓ Extracted 8,472 positions from 387 games

Training on 8,472 positions
Epoch 1/10 - Loss: 0.4521
Epoch 2/10 - Loss: 0.3187
...
Epoch 10/10 - Loss: 0.1243

✓ Saved final model: supervised_final.pt
```

**What you get:**
- Network that understands basic chess patterns
- Can recognize tactics (pins, forks, skewers)
- Knows endgame technique (K+P vs K, R+P vs R)
- Still needs refinement for creativity

---

### Step 3: Generational Self-Play
```bash
cd v7.0/src
python train_v7_2_complete.py
```

**What it does:**
1. Loads supervised model as Generation 0
2. Trains new generation via 100-game self-play
3. Evaluates new vs old in 6-game match
4. Accepts if improvement detected (>50% win rate)
5. Repeats for N generations

**Expected results (v7.2 vs v7.1):**

| Metric | v7.1 (Random Gen 0) | v7.2 (Supervised Gen 0) |
|--------|---------------------|-------------------------|
| Gen 1 evaluation | 0-6-0 (6 draws) | 3-2-1 (3 wins!) |
| Win rate | 0% | 50% |
| Acceptance rate | 0% | 60-80% |
| Draw rate | 90% | 40-50% |
| Max-move games | 85% | 50-60% |

**Why supervised baseline works:**
- Gen 0 can actually play chess (not random)
- Gen 1 has meaningful target to beat
- Evaluation produces decisive games
- Network improves through self-play refinement

## Technical Details

### Supervised Training Parameters
```python
target_weight = 0.85  # Base target for winning positions

# Phase-aware targets:
# Opening (moves 1-15):  0.6  (learning fundamentals)
# Middlegame (16-35):    0.85 (learning tactics)
# Endgame (36+):         0.93 (learning technique)
```

### Why Winner-Only?
```
Game Result: 1-0 (White wins)

White's perspective:
  Move 10: +0.6 (opening advantage)
  Move 20: +0.85 (middlegame tactic)
  Move 40: +0.93 (endgame conversion)

Black's perspective:
  SKIPPED (lost the game)
```

**Learning principle:**
> "We don't learn from losing moves. Only from winning moves."

### Position Filtering
- Skip moves 1-5 (opening book territory)
- Skip positions with <8 pieces (tablebase territory)
- Skip drawn games (no winner to learn from)
- Skip incomplete games (Result: *)

## Troubleshooting

### "No positions extracted"
**Cause:** Cleaned PGN files don't exist

**Solution:**
```bash
cd v7.0/src
python pgn_preprocessor.py
# Creates /cleaned subdirectories
```

### "Supervised model not found"
**Cause:** Haven't run supervised training yet

**Solution:**
```bash
cd v7.0/src
python supervised_gm_trainer.py
# Creates supervised_final.pt
```

### "All games still drawing"
**Possible causes:**
1. Supervised model didn't train properly (check loss)
2. Need more GM games (increase dataset)
3. Self-play games too short (increase from 100 to 200)

**Diagnostic:**
```bash
# Test supervised baseline
cd v7.0/src
python -c "
from supervised_gm_trainer import SupervisedGMTrainer
import torch

trainer = SupervisedGMTrainer('../profiles/dark_forest_assassin.json')
trainer.network.load_state_dict(torch.load('../training/v7_supervised/supervised_final.pt'))

# Should be able to recognize basic positions
# Test manually or in Arena GUI
"
```
