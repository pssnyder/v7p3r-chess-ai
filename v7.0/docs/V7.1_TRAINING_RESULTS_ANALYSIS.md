## Root Cause Analysis

### Primary Issue: Weak Baseline

**Problem**: Generation 0 has random weights
- Can't recognize simple tactics (pins, forks, skewers)
- Can't convert K+P vs K endgames
- Wanders aimlessly when ahead
- No understanding of piece coordination

**Result**: When Gen 1 plays Gen 0:
- Both play randomly (Gen 1 only slightly less random)
- Neither can finish games
- Draws are inevitable

### Secondary Issue: Insufficient Training Volume

**100 games at ~170 positions/game = 17,000 training examples**

But:
- Network has 55,425 parameters
- Needs ~10-50x more data for convergence
- AlphaZero used millions of games

### Tertiary Issue: Conservative Evaluation

**Temperature 0.1 in evaluation** → ultra-defensive play
- Always picks "safest" move
- Avoids tactical complications
- Prefers repetition over risk
- Causes draw-heavy matches

## Solutions (Ordered by Effectiveness)

### 🥇 Solution 1: Pre-Train Generation 0 (RECOMMENDED)

**File**: `train_generational_v2.py` (already created)

**Changes**:
- Train Gen 0 with 500 self-play games FIRST
- Then run generational training from this baseline
- This creates a "competent but improvable" starting point

**Expected Results**:
- Gen 0 can finish K+P vs K in <100 moves
- Gen 0 understands basic tactics
- Gen 1 has a meaningful target to beat
- Acceptance rate: 40-60% (healthy)

**Runtime**: ~4-6 hours for baseline + 10-15 hours for generations = 14-21 hours total

### 🥈 Solution 2: Increase Self-Play Volume

**Change**: `SELFPLAY_GAMES = 100` → `500` (or 1000)

**Pros**:
- More training data per generation
- Better convergence
- Network sees more positions

**Cons**:
- 5-10x longer training time
- May still struggle with weak baseline

**Expected Results**:
- Training loss drops further (0.11 → 0.05)
- Slight improvement in game quality
- Still may get all draws if baseline is too weak

### 🥉 Solution 3: Raise Evaluation Temperature

**Change**: `temperature=0.1` → `0.3` (in `_play_evaluation_game`)

**Pros**:
- More decisive games
- Less draw-heavy
- Better exploration

**Cons**:
- May accept inferior models due to randomness
- Less stable evaluation

**Expected Results**:
- Draw rate: 90% → 50-60%
- More wins/losses
- May need more evaluation games (6 → 10) for stability

### 🏅 Solution 4: Hybrid Supervised Learning

**Approach**: Train Gen 0 on Stockfish games instead of self-play

**Method**:
1. Generate 10,000 positions with Stockfish
2. Train network to predict Stockfish evaluations
3. Use this as Gen 0 baseline
4. Run generational training

**Pros**:
- Much stronger baseline
- Network starts with chess knowledge
- Faster convergence

**Cons**:
- Requires separate training script
- More complex workflow
